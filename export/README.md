# EDB PostgreSQL monitoring: Grafana import

Generated by `scripts/edb-dashboards/export_bundle.py`. Do not edit these files; regenerate them.

| File | Content |
|---|---|
| `edb-grafana-bundle.json` | Everything in one file: 3 dashboards + 30 alert rules |
| `import-to-grafana.py` | Imports the bundle through the Grafana API (Python 3, standard library only) |
| `dashboards/*.json` | One dashboard per file, for manual import in the UI |
| `alerts/edb-postgres-alerts.rules.yaml` | Alert rules as Prometheus rule file, for manual import in the UI |

Dashboards: Cluster Overview, Backups, Alert Center. All land in folder **EDB PostgreSQL**.

## Prerequisites

- A Prometheus/Thanos datasource that scrapes the EDB instances via a `PodMonitor` on port `metrics`
  (do not name the PodMonitor like the Cluster; the operator deletes it).
- Grafana 12 or newer for the alert import (tested with Grafana 13.2.4). Dashboards alone also work on older versions.

## Option 1: script (recommended)

Create a service account token in Grafana (Administration → Service accounts, role Editor), then:

```bash
export GRAFANA_URL=https://grafana.customer.example
export GRAFANA_TOKEN=glsa_...
python3 import-to-grafana.py
```

Optional: `PROM_DS_UID=<uid>` (datasource for the alert rules, default = default Prometheus datasource),
`ALERTS_PAUSED=1` (import rules paused), `ALERTS=none` (dashboards only), `GRAFANA_INSECURE=1` (self-signed TLS).
Re-running is safe: dashboards and rule groups are replaced, not duplicated.

## Option 2: Grafana UI

1. Dashboards → New → Import → upload each file from `dashboards/` → folder "EDB PostgreSQL".
2. Alerting → Alert rules → More → Import alert rules → **Prometheus YAML file** → `alerts/edb-postgres-alerts.rules.yaml`.

## Where alerts go

Without mail/chat, Grafana is the alert sink: open **EDB PostgreSQL — Alert Center** (wall screen: append `?kiosk`).

| Rules evaluated by | How deployed | Alert inbox | Counters, table, history, alert rows on the other dashboards |
|---|---|---|---|
| Grafana | this bundle (Option 1/2) | yes | no: they read Prometheus' `ALERTS` series, which Grafana-evaluated rules do not write |
| Prometheus | `manifests/edb-postgres-alerts.yaml` (PrometheusRule) + `ALERTS=none` | yes | yes |

Pick one per Grafana: importing the rules **and** deploying the PrometheusRule evaluates every rule twice.
Per-rule history for Grafana-evaluated rules: Alerting → Alert rules → rule → History.
